# LogicaFuzzy

Projeto de demonstração de lógica fuzzy aplicada ao controle de um drone em simulação. O repositório contém uma aplicação React/Vite que usa um controlador fuzzy Mamdani implementado em JavaScript para ajustar a altitude e o movimento horizontal do drone em um ambiente 3D.

A pasta `drone-fuzzy-react/` abriga a interface interativa, a física da simulação e o pipeline fuzzy que mostra visualmente os graus de pertinência, regras e decisões de controle.
